# 📘 Raw Material Documentation

---

## 1. ➕ Add New Stock

| Step | Action |
|------|--------|
| 1 | Navigate to **OPERATIONS** → Click **Add Stock** |
| 2 | Enter **Fabric Number** (the fabric to add stock for) |
| 3 | Enter **Stock Quantity** |
| 4 | Enter **Location** |
| 5 | Click **Add Stock** ✅ |

> **Tip:** Ensure the fabric number exists in the system before adding stock.

---

## 2. 📦 Ship Stock

| Step | Action |
|------|--------|
| 1 | Navigate to **OPERATIONS** → Click **Ship Stock** |
| 2 | Scan **Order ID QR Code** |
| 3 | Once the fabric is updated successfully, scan the next **Order ID QR Code** |
| 4 | Repeat until all stock is shipped |

> **Note:** Scanning order IDs sequentially ensures accurate stock tracking.

---

## 3. 📝 Create/Update Stock Details (Bulk Upload)

| Step | Action |
|------|--------|
| 1 | Navigate to **BULK OPERATION** → Click **Upload Stock** |
| 2 | **Download Sample File** |
| 3 | Open **Google Sheet** → Search for *Fabric Average Sheet* |
| 4 | Go to **Fabric Style Map** tab |
| 5 | Copy **Fabric Name, Fabric #, Style #s** |
| 6 | Paste data into the downloaded sample file |
| 7 | **Upload File** |
| 8 | Verify new stock entry creation/update ✅ |

> **Pro Tip:** Always maintain consistent style numbers to avoid duplicates.

---

## 4. 📊 Add/Update Averages

| Step | Action |
|------|--------|
| 1 | Navigate to **BULK OPERATION** → Click **Upload Averages** |
| 2 | **Download Sample File** |
| 3 | Open **Google Sheet** → Search *Fabric Average Sheet* |
| 4 | Go to **Pattern Average** tab |
| 5 | Copy data from **Row A3** (or rows to update) |
| 6 | Paste into the downloaded sample file |
| 7 | **Upload File** ✅ |

> **Tip:** Check for empty cells; missing averages can cause calculation errors.

---

## 5. 🎨 Add/Update Style Numbers with Patterns

| Step | Action |
|------|--------|
| 1 | Navigate to **BULK OPERATION** → Click **Upload Fabric** |
| 2 | **Download Sample File** |
| 3 | Open **Google Sheet** → Search *Fabric Average* |
| 4 | Go to **Style-Pattern-Fabric Mapping** tab |
| 5 | Copy data from **Row A2** (or rows to update) |
| 6 | Paste into the downloaded sample file |
| 7 | **Upload File** ✅ |

---

## 6. ⚖️ Add/Update Average Relations (Meter & Weight)

| Step | Action |
|------|--------|
| 1 | Navigate to **BULK OPERATION** → Click **Upload Relations** |
| 2 | **Download Sample File** |
| 3 | Open **Google Sheet** → Search *Purchase, Invoice, and Payment* |
| 4 | Go to **Fabric** tab |
| 5 | Copy the required **Fabric #, Meter, Weight** relationships |
| 6 | Paste into the downloaded sample file |
| 7 | **Upload File** ✅ |

> **Reminder:** Correct meter-to-weight mapping is critical for accurate production planning.

---

## 7. 🚨 Low Stock Alerts

| Step | Action |
|------|--------|
| 1 | Navigate to **Monitoring** → Click **Low Stock Alert** |
| 2 | **Download CSV File** for detailed information |

> **Tip:** Monitor low stock daily to prevent production delays.

---

### ⚡ Professional Tips
- Keep Google Sheets synchronized with the system to reduce upload errors.  
- Always verify data before uploading bulk files.  
- Use consistent naming conventions for fabrics and styles.  
- Regularly review low stock alerts to maintain smooth operations.
